# Corrections already made — do not repeat

Project-specific instances (the exact wrong name, the auto-linking word) live in the project
file's **Domain notes**. The rules below hold everywhere.

| What went wrong | What he said | Rule |
|---|---|---|
| 12 follow-ups of under 1k characters each | "poorly defined, they lack context. An agent would suffer…" | Every ticket gets the full template, even in a batch. |
| Wrong collection name, guessed from a similar one | "… is wrong – we have a … collection" | Read the names from code. |
| Diagnosis assumed the new code path | "only 3 companies using the new counter… assume the old path" | Check which path most users or tenants run. |
| Claims without data | "chasing ghosts… provide tangible examples" | Concrete record IDs or no claim. |
| Customer named without proof | "You are name dropping now" | Only name customers the data shows are affected. |
| Code pasted as instructions | "considered untrusted and a risk" | Describe it, don't paste it. |
| Answered question still read "proposed" | "make it so the ticket states exactly that" | Rewrite answered questions as settled facts. |
| Follow-ups under the shipping epic | "does that mean… finish the follow ups prior to launching?" | Ask; default to a follow-up epic. |
| Unclear grooming question | "I don't understand this question" | Plain words, concrete options. |
| A word auto-linked to an initiative, `## Notes## Notes`, labels added twice, bug label attached an SLA | (caught after saving) | Step 4 check after saving, every time. |
| Bug filed then disproved by a test | — | If evidence disproves it, don't file. Fix earlier comments. |
